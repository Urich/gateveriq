## Slider puzzles and expiring contexts

- Replace image-category selection with compact slider puzzles using freshly generated local landscapes. No external image service is required.
- Add light, dark, automatic and custom themes, CSS variables, Shadow DOM isolation and an optional style nonce. The 304 px widget scales to narrow containers and supports mouse, touch and keyboard input.
- Issue authenticated, expiring operation contexts through `POST /internal/v1/contexts`. Context signatures bind the integration, action and deadline; expired contexts remain invalid after database cleanup and restart. Remove the permanent used-context ledger.
- Preserve PoW, exact-origin and account binding, three-answer budgets, fixed deadlines and single-use token consumption. Incorrect slider positions regenerate the puzzle without resetting its budget or deadline.
- Update the SDK, local demo, integration documentation and security tests.

## Breaking changes

- Start with a fresh database. Migration of v0.1.0 databases is not supported; back up existing data before replacing a deployment and create new integrations for the fresh database.
- Arbitrary context IDs and random 32-byte contexts are rejected. Obtain signed contexts from the internal API. SDK `createAttempt()` is now asynchronous: await it, persist its result, then prepare the attempt.
- Visual submissions use an integer `position` instead of `selected` indexes. The response uses `kind: "slider_puzzle"`, `background`, `piece` and geometry metadata. The consume method remains `pow_visual`.
- Serve `widget.js`, `slider.js` and `worker.js` together on your application origin. See [embedding and themes](https://github.com/Urich/gateveriq/blob/v0.2.0/docs/website-integration.md#slider-themes-and-embedding).

## Downloads and limitations

The release provides an Ubuntu 24.04 amd64 archive and SHA-256 checksum. The Docker image is `ghcr.io/urich/gateveriq:v0.2.0`.

This remains an experimental MVP. Slider completion is not proof of human presence; computer vision and blind guessing remain possible. The previously reported SQLite dependency advisory and shared-proxy IP-history limitations are not fixed by this release. See the [security review](https://github.com/Urich/gateveriq/blob/v0.2.0/docs/security-review-2026-11-14.ru.md).
