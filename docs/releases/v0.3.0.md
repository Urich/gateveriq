## Optional login failure reset after slider verification

- Set `reset_account_failures_on_slider_success = true` under `[website]` to reset the login failure count for the account, action and integration after successful slider and PoW verification.
- The option defaults to `false`. Each challenge can reset the count once, so replaying a solved challenge preserves later login failures.
- Existing v0.2.0 databases can be opened directly. The server creates the new table on startup.
