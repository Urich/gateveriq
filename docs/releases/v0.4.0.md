## Slider puzzles

- Each challenge generates a fresh alpine lake, desert, coastline, or northern lights scene.
- The movable piece uses one of six silhouettes. Two decoy cutouts use the same silhouette, and all three cutouts sit at distinct heights.
- The slider still moves horizontally. Existing widget integrations can use the new puzzles without changes.

## Distribution

- Docker image: `ghcr.io/urich/gateveriq:v0.4.0`.
- GitHub Releases provides the Ubuntu 24.04 amd64 archive and its SHA-256 checksum.
