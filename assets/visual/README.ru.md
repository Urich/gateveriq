# Пробный набор иллюстраций

[English](README.md) | [Русский](README.ru.md)

Изображения созданы заранее встроенным инструментом image_gen. При работе
сервиса внешняя генерация не используется. Исходные английские промпты
сохранены без изменений в [prompts.json](prompts.json).

Каждый исходный PNG — атлас 2×2 с четырьмя вариантами:

| Файл | Категория |
|---|---|
| cats.png | Кошки |
| dogs.png | Собаки |
| bicycles.png | Велосипеды |
| cars.png | Машины |
| flowers.png | Цветущие растения в горшках |
| trees.png | Деревья |

В `tiles/` подготовлены 24 PNG размером 160×160. После замены атласов
пересоздайте отдельные картинки:

```sh
cargo run --locked --example prepare_visual
```

Затем пересоберите и перезапустите сервер: картинки встраиваются в бинарный
файл, а их data URL кешируются. Масштабирования во время HTTP-запроса нет.
Публичная задача содержит сами картинки без имён файлов и меток категорий.
Каждое поле содержит 16 разных изображений; выбирать нужно тип предмета,
совпадающий с образцом.

После ошибки предмет и подборка меняются без сброса срока действия и бюджета.
Сохранённые задачи сохраняют картинки до смены или истечения срока.
Подробнее: [подключение сайта](../../docs/ru/website-integration.md).

Это проба оформления, а не промышленный набор CAPTCHA. Бот может распознать
или запомнить 24 статические картинки. Категории известны из исходного кода.
Увеличение набора улучшает разнообразие, но не доказывает присутствие человека.
